# OMH Foundations

Hardware and low-level systems from first principles: a lab-driven course for a strong software engineer founding OMH, a company that designs, builds and supports its own rack-scale server modules.

The course starts at electrons. It ends with two machines you built from the transistor up. One is a quadcopter that flies on your firmware, your boards, your radio protocol and a TI radar altimeter. The other is Module Zero, a two-node fleet of server modules that attest their firmware, form a quorum, run tenant VMs on your hypervisor and store data erasure-coded across NVMe.

## The books

| PDF | Contents |
|---|---|
| [0. Handbook](pdf/OMH-Foundations-0-Handbook.pdf) | How the course works, bench safety, the complete kit list with part numbers, sellers and prices, setup, the reference library and a progress tracker |
| [1. Circuits, Sensors and Signals](pdf/OMH-Foundations-1-Circuits-Sensors-and-Signals.pdf) | Electricity and measurement; the analogue signal chain; sensors with TI silicon; power conversion and batteries; signals on wires and RF |
| [2. Logic, Processors and Firmware](pdf/OMH-Foundations-2-Logic-Processors-and-Firmware.pdf) | Digital logic; HDL and FPGA; a pipelined RISC-V CPU; memory and interconnect; privilege; bare-metal firmware on the MSP432E401Y; boot and platform firmware |
| [3. Control, Radio and Boards](pdf/OMH-Foundations-3-Control-Radio-and-Boards.pdf) | Motor control and estimation; radio links on the CC1312R; microwave synthesis and FMCW radar; four boards designed and brought up; the drone |
| [4. Systems Software and the Product](pdf/OMH-Foundations-4-Systems-Software-and-the-Product.pdf) | A kernel; Linux internals; Linux drivers for TI parts; virtualisation; storage and network data paths; product engineering; the Module Zero capstone |

Start with the Handbook. Every chapter has the same shape: why it matters to OMH, a skip test, core ideas with figures, a reading list, labs with measurable done-when criteria and an evidence list, a problem set, and a completion checklist. Each unit ends with a sign-off page.

The course takes about 80 weeks at 12 to 15 hours a week. The kit is listed by unit in the Handbook. Every item has an exact part number, a link to the seller's page, and the price checked on 4 October 2026.

The required kit costs about £5,450 from UK sellers, VAT included. Add about US$475 and €145 from overseas sellers, before import VAT. Three things are budgeted separately: a used rack server, a used enterprise NVMe drive, and fabrication of the four boards. Unit 1, which buys the bench instruments, accounts for more than half of the UK total.

## Building the PDFs

The PDFs are typeset with [Typst](https://typst.app) from the sources in `src/`. The figures are generated by Python.

```sh
cd src
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
./build.sh
```

The build needs Typst 0.15 or later and Python 3.12 or later. The fonts are bundled in `src/fonts` under their open licences. `build.sh` regenerates every figure, extracts the lab list for the Handbook's tracker, and writes the five PDFs to `pdf/`.

| Path | What it holds |
|---|---|
| `src/lib/template.typ` | The page design and every component: labs, checklists, kit tables, sign-off pages |
| `src/h/`, `src/u1/` to `src/u4/` | The Handbook parts and the unit chapters |
| `src/diagrams/` | The figure library (`omhfig.py`) and one script per unit |
| `src/kit.yaml` | The kit list; the Handbook's tables and totals are generated from it |
| `src/tools/labs.py` | Builds the lab list for the progress tracker |
