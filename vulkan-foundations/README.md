# Vulkan Foundations

Explicit GPU programming from first principles: a lab-driven course in Vulkan for C++ programmers who have never used it. It treats the GPU as a separate computer with its own memory, queues and timeline, starts with compute shaders, gives synchronisation a unit of its own, and compares every idea with OpenGL.

The course builds a compute program against the raw C API with nothing hidden, a library of parallel primitives, a ray tracer in compute shaders, a synchronisation toolkit ending in a render graph, a renderer with GPU culling and indirect draws, a port from OpenGL with the CPU cost of each API measured, and a GPU-driven capstone.

## The books

|---|---|

Start with the Handbook. Every chapter has the same shape: why it matters, a skip test, core ideas with figures and listings, a reading list, labs with measurable done-when criteria and an evidence list, a problem set, and a completion checklist. Each unit ends with a sign-off page.

The course takes about 170 hours. It needs a GPU with a Vulkan 1.3 driver, the Vulkan SDK, a C++20 compiler, CMake, Ninja and, for Unit 4, GLFW.

## The companion code

`code/` holds every lab project, one directory each, and `vkf`, the small helper library that Unit 1 builds up to. Every listing in the PDFs is taken from these files, and every program checks its own results.

```sh
cd code
cmake -S . -B build -G Ninja
cmake --build build
./build/bin/vkf_selftest
```

The Handbook's setup part covers each platform, including the Homebrew route on macOS.

## Building the PDFs

The PDFs are typeset with [Typst](https://typst.app) from the sources in `src/`. The figures are generated by Python.

```sh
cd src
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
./build.sh
```

The build needs Typst 0.15 or later and Python 3.12 or later. The fonts are bundled in `src/fonts` under their open licences. `build.sh` regenerates every figure, extracts the lab list for the Handbook's tracker, writes the five PDFs to `pdf/`, and packs the code into `pdf/Vulkan-Foundations-Code.zip`.

| Path | What it holds |
|---|---|
| `src/lib/template.typ` | The page design and every component: labs, listings, checklists, sign-off pages |
| `src/h/`, `src/u1/` to `src/u4/` | The Handbook parts and the unit chapters |
| `src/diagrams/` | The figure library (`vkfig.py`) and one script per volume |
| `src/console/` | Output captured from real runs of the companion code; the PDFs quote most of it |
| `src/tools/` | The lab list for the progress tracker and the code archive |
