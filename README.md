# Courses

Self-directed, lab-driven courses. Each directory is one course with its own README.

| Course | What it covers |
|---|---|
| [Hardware and Systems](hardware-and-systems/README.md) | Hardware and low-level systems from first principles, as a handbook and four typeset units (PDF): electronics and TI sensors, power, RF, digital logic, FPGA, a CPU, firmware, boot chains, motor control, radio links, microwave radar, board design, a drone, kernels, drivers, hypervisors, storage and network data paths, and the engineering of a server product |
| [ML Foundations](ml-foundations/README.md) | Machine learning from the maths to a trained model: probability and linear algebra, classical supervised learning, clustering, dimensionality reduction, training neural networks, convnets, autoencoders and diffusion, self-supervised learning, transformers and LLMs, reinforcement learning, experimentation and causality, ML systems and governance |
| [Vulkan](vulkan/README.md) | Explicit GPU programming with Vulkan from first principles, as a handbook, four typeset units (PDF) and verified companion code: instances, memory and pipelines, compute shaders and parallel patterns, a ray tracer, barriers, semaphores, queues and frames in flight, render graphs, the graphics pipeline and presentation, a port from OpenGL, and a GPU-driven capstone |
| [Machine Learning](machine-learning/README.md) | Neural networks and language models from first principles, as a handbook, four typeset units (PDF) and verified companion code: tensors and an autograd library, optimisers, generalisation and representations, a tokeniser, attention and a transformer pretrained from scratch, scaling laws, decoding and interpretability, fine-tuning, LoRA, DPO and GRPO on open weights, evaluation, retrieval and agents, GPU kernels in Metal or Vulkan, parallel training, a C++ inference engine, quantisation and serving |
