# AI Foundations

Neural networks and language models from first principles: a lab-driven course for programmers who know Python well and have never trained a model. It builds an automatic differentiation engine and derives the networks of modern machine learning from it, writes a language model from an empty file and pretrains it, turns an open-weight model into an assistant by the methods the large laboratories use, and makes all of it fast, down to GPU kernels and an inference engine in C++.

The course builds `tiny`, an autograd library whose gradients match PyTorch's to within rounding; a tokeniser that encodes text exactly as SmolLM2's does; a 28-million-parameter transformer pretrained on 300 million tokens of children's stories; scaling laws that predict a run's loss; supervised fine-tuning, LoRA, DPO and GRPO written from scratch; an evaluation harness with honest confidence intervals; retrieval with an HNSW index and an agent that calls tools; matrix multiplication, softmax and FlashAttention as Metal or Vulkan kernels; data, tensor and pipeline parallelism; an inference engine in C++ with 8- and 4-bit weights; and a server with continuous batching, a paged KV cache and speculative decoding.

Start with the Handbook. Every chapter has the same shape: why it matters, a skip test, core ideas with figures and listings, a reading list, labs with measurable done-when criteria and an evidence list, a problem set, and a completion checklist. Each unit ends with a sign-off page.

The course takes about 200 hours of study, plus unattended training time. It needs Python 3.12 through `uv`, and ideally a GPU: an Apple Silicon Mac or an NVIDIA card. Chapters 4.6 and 4.7 need a C++20 compiler, CMake and Ninja, and the Vulkan track of Chapter 4.4 the Vulkan SDK.

## The companion code

`code/` holds every program, in one package per unit, `u1` to `u4`, and `aif`, the helper package that the units build up: data downloads, `tiny`, the tokeniser, the transformer, the training loop, the samplers, LoRA, the evaluation harness and the serving system. Every listing in the PDFs is taken from these files, and every program checks its own results.

```sh
cd code
uv sync
uv run -m aif.selftest --download
uv run -m u1.gradcheck
```

The C++ inference engine and the Vulkan kernels build with CMake:

```sh
cmake -S . -B build -G Ninja
cmake --build build
./build/bin/aif_engine runs/engine/tinystories-28m-f32.bin --check
```

Every dataset and model is downloaded from the Hugging Face Hub at a pinned revision. The Handbook's setup part lists them with their sizes and licences.

## Building the PDFs

The PDFs are typeset with [Typst](https://typst.app) from the sources in `src/`. The figures are generated by Python from the measurements in `src/data`.

```sh
cd src
./build.sh
```

The build needs Typst 0.15 or later and the companion code's environment. The fonts are bundled in `src/fonts` under their open licences. `build.sh` regenerates every figure, extracts the lab list for the Handbook's tracker, writes the five PDFs to `pdf/`, and packs the code into `pdf/AI-Foundations-Code.zip`.

| Path | What it holds |
|---|---|
| `src/lib/template.typ` | The page design and every component: labs, listings, checklists, sign-off pages |
| `src/h/`, `src/u1/` to `src/u4/` | The Handbook parts and the unit chapters |
| `src/diagrams/` | The figure library (`aifig.py`) and one script per volume |
| `src/console/` | Output captured from real runs of the companion code on an Apple M2 Pro |
| `src/data/` | The measurements the figures are drawn from |
| `src/tools/` | The lab list for the progress tracker and the code archive |
